
# Ashisraj Portfolio

This is a personal portfolio website built using React and Tailwind CSS.

## Deployment (Vercel)

1. Go to https://vercel.com
2. Click **New Project**
3. Import this folder (drag and drop if zipped)
4. Follow the instructions (it will auto-detect React)
5. Click **Deploy**

After a few seconds, your portfolio will be live!

---
If you want a custom domain, you can add it later from your Vercel dashboard.
